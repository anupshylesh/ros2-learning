# ROS 2 Python Package

This package contains my ROS 2 Python learning exercises and projects developed using ROS 2 Jazzy and Ubuntu.

## Topics Covered

- Creating ROS 2 nodes
- Publishers and subscribers
- Services and clients
- ROS 2 parameters
- Robot status publishing
- Battery status
- Inter-node communication
- Basic robotics communication projects

## Python Examples

| File | Description |
|---|---|
| `my_first_node.py` | Basic ROS 2 Python node |
| `pub_number.py` | Publishes numerical data |
| `sub_number.py` | Subscribes to numerical data |
| `add_two_ints_server.py` | ROS 2 service server |
| `add_two_ints_client.py` | ROS 2 service client |
| `robot_news_station.py` | Publishes robot news |
| `robot_status.py` | Publishes robot status |
| `battery.py` | Battery status example |
| `led_panel.py` | LED panel control example |
| `project_one_pub.py` | Project publisher node |
| `project_one_sub.py` | Project subscriber node |
| `smartphone.py` | ROS 2 communication example |

## Environment

- ROS 2 Jazzy
- Ubuntu Linux
- Python 3
- rclpy

## Purpose

This package is part of my ongoing ROS 2 and robotics learning journey, focusing on Python-based ROS 2 development and robot communication.
